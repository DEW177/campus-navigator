# ตำแหน่งปัจจุบันและการนำทางจากบ้านหรือหอ

## การใช้งาน

1. ค้นหาแล้วเลือกห้อง ไม่ต้องกรอกที่อยู่ ชั้น หรือชื่อจุดเริ่มต้น
2. กด **นำทางจากตำแหน่งของฉัน** แล้วอนุญาตตำแหน่ง
3. กด **เปิดเส้นทางไปอาคารใน Google Maps** เพื่อดูเส้นทางถนนและเลือกวิธีเดินทาง
4. เมื่อถึงทางเข้าที่ระบุ กลับมาที่เว็บแล้วกด **ดูเส้นทางจากทางเข้าไปห้อง**

Google Maps เปิดในแอปหรือแท็บใหม่ ส่วนเว็บยังเก็บห้องและผังไว้ ไม่ต้องใช้ API key
ในรุ่นนี้เส้นทางถนนจะแสดงใน Google Maps; แผนที่บนเว็บแสดงจุดตำแหน่งและทางเข้า
ไม่ได้ลากเส้นตรงจากบ้านไปอาคารแล้วเรียกว่าเส้นทางเดิน

ตำแหน่งอ่านเมื่อกดปุ่มเท่านั้น ไม่ติดตามตลอดเวลา ไม่อนุมานชั้นที่ยืนอยู่ และไม่เก็บ
พิกัดมือถือใน URL, localStorage, sessionStorage หรือฐานข้อมูลของโปรเจค
หลังรีเฟรชต้องกดขอตำแหน่งใหม่ ส่วนวิธีขึ้นลงชั้น ชั้นที่ดู และเส้นทางภายในอาคาร
ที่เคยขอไว้ยังคืนค่าได้ โดยคำนวณจากทางเข้าใหม่ด้วยข้อมูลปัจจุบัน

ถ้าไม่อนุญาตตำแหน่ง สัญญาณไม่พร้อม หรือหมดเวลา จะมีคำอธิบายและปุ่มลองใหม่
ยังดูตำแหน่งอาคารหรือเปิดผังได้ และยกเลิกการรอตำแหน่งได้

## ทดสอบบนคอม

รัน `docker compose up --build` แล้วเปิด `http://localhost:3000` บนเครื่องเดียวกัน
เบราว์เซอร์อนุญาต Geolocation บน localhost แต่ความแม่นยำของคอมอาจต่างจากมือถือ

## ทดสอบบนมือถือ: ต้องใช้ HTTPS

`http://<IPคอม>:3000` เปิดดูเว็บได้ แต่เบราว์เซอร์มือถือทั่วไปไม่อนุญาตให้เว็บนั้น
อ่านตำแหน่ง ต้องใช้ HTTPS ที่มือถือเชื่อถือ หากมีเว็บที่เผยแพร่ผ่าน HTTPS แล้ว
ให้ใช้ที่อยู่นั้นได้เลย ส่วนการทดสอบใน Wi-Fi เดียวกันมีตัวเลือกด้านล่าง

### HTTPS ในเครื่องด้วย Docker และ mkcert

1. ติดตั้ง [mkcert ตามคู่มือของโครงการ](https://github.com/FiloSottile/mkcert#installation)
   สำหรับ Windows ใช้ไฟล์ release หรือ package manager ที่ติดตั้งอยู่
2. เปิด PowerShell ที่โฟลเดอร์โปรเจค ใช้ `ipconfig` หาค่า IPv4 ของ Wi-Fi
   แล้วแทน `192.168.1.20` ด้านล่างด้วย IP ของคอมจริง:

   ```powershell
   New-Item -ItemType Directory -Force certs
   mkcert -install
   mkcert -cert-file certs/cert.pem -key-file certs/key.pem localhost 127.0.0.1 192.168.1.20
   mkcert -CAROOT
   ```

3. ติดตั้ง **rootCA.pem** จากโฟลเดอร์ที่คำสั่งสุดท้ายแสดง ลงบนมือถือทดสอบตาม
   [คำแนะนำ Mobile devices](https://github.com/FiloSottile/mkcert#mobile-devices)
   ให้เบราว์เซอร์เชื่อถือ CA นี้ บน iOS ต้องเปิด full trust เพิ่มด้วย
   ใช้เฉพาะ rootCA.pem; ไม่ส่ง `rootCA-key.pem` หรือ `certs/key.pem` ไปมือถือหรือ GitHub
4. เริ่ม HTTPS gateway:

   ```powershell
   docker compose -f docker-compose.yml -f docker-compose.https.yml up --build
   ```

5. เปิด **https://192.168.1.20:3443** จากมือถือใน Wi-Fi เดียวกัน ต้องไม่มีคำเตือน
   certificate แล้วลอง SC06-301 → นำทางจากตำแหน่งของฉัน
   ถ้าเชื่อมต่อไม่ได้ ให้ตรวจ firewall สำหรับ TCP 3443 บนเครือข่ายส่วนตัว

หาก IP คอมเปลี่ยน ให้สร้าง cert ใหม่สำหรับ IP นั้นแล้ว restart service `https`
ไฟล์ certs ถูกละเว้นจาก Git; การติดตั้งและเชื่อถือ certificate เป็นขั้นตอนบนอุปกรณ์ทดสอบ
การรัน HTTP ปกติและฐานข้อมูลเดิมไม่ได้ถูกแทนที่โดยไฟล์ Compose เสริมนี้

## ข้อมูลที่ต้องใส่เมื่อมีอาคารจริง

ตาราง `building_entrances` ผูกอาคารกับ node ทางเข้าหนึ่งจุด และเก็บละติจูด/ลองจิจูด
ของ **ทางเข้านั้น** โดยตรง ไม่ใช้พิกัดกลางอาคารเป็นทางเข้าโดยอัตโนมัติ
node มี `kind=entrance`; ถ้าเชื่อมผังในอาคารต้องมี floor ID, เลขชั้น และ x/y
ที่ตรงอาคารและอยู่ในขอบเขตภาพ จากนั้นจึงเชื่อมทางเดินไปยังประตูห้อง

ถ้ายังไม่มีข้อมูลทางเข้า ระบบจะแจ้งและให้ดูผังได้ ไม่เลือกจุดใกล้เคียงเอง
การนำทางช่วงภายนอกและภายในยังเป็นสองช่วง ผู้ใช้เป็นคนเปิดดูช่วงถัดไป
ระบบไม่ได้ตรวจว่ามาถึงหรือเปลี่ยนชั้นอัตโนมัติ
