# ค้นหาจุดเริ่มต้นและดูเส้นทางกลางแจ้ง

## การใช้งาน

1. ค้นหาห้องและเลือกปลายทาง เช่น SC06-301 (พิกัดตัวอย่าง)
2. เลือกจุดเริ่มต้นด้วยตำแหน่งปัจจุบัน, ค้นหาสถานที่/ที่อยู่ หรือแตะปักหมุด
3. การค้นหาส่งคำขอเมื่อกด **ค้นหา** หรือ Enter เท่านั้น ไม่ส่งขณะพิมพ์
   ค้นหาในประเทศไทยและจัดลำดับใกล้ทางเข้าอาคารก่อน เพิ่มจังหวัดเมื่อชื่อซ้ำ
4. เมื่อเลือกผลค้นหาหรือปักหมุด ให้ตรวจตำแหน่งแล้วกด **ใช้จุดนี้เป็นจุดเริ่มต้น**
   หมุดที่เลือกเองไม่ถูกเรียกว่า GPS ที่ระบบตรวจพบ
5. เลือก **เดิน / ขับรถ** แล้วกด **ดูเส้นทางบนแผนที่**
6. เว็บแสดงเส้นทาง ระยะทางและเวลาโดยประมาณ ต่อด้วยส่วน **จากทางเข้าไปห้องเรียน**
   ตามข้อมูลผังที่มี Google Maps เป็นปุ่มทางเลือกเมื่อมีจุดเริ่มต้น

หมุดไม่ติดตามสด ไม่มีเสียงบอกเลี้ยว ไม่มีการเปลี่ยนเส้นทางอัตโนมัติเมื่อออกนอกทาง
เวลาไม่รวมจราจรสดหรือเส้นทางภายในอาคาร เส้นทางรถยังไม่ได้ระบุที่จอดรถ
ถ้าปลายเส้นทางอยู่ห่างจากประตู เว็บแจ้งระยะห่างเมื่อเกิน 20 เมตร ไม่ลากเส้นตรงเชื่อมแล้วอ้างว่าเดินได้
SC06/RC01 ยังเป็นข้อมูลตัวอย่าง แม้เส้นทางมาจากบริการจริงก็ยังไม่ได้ยืนยันประตูจริง
DEMO ไม่มีพิกัดโลกจริง จึงทดลองเฉพาะผังในอาคาร ไม่ส่งปลายทาง 0,0

## ใส่ API key ภายหลัง

บัญชี [Geoapify MyProjects](https://myprojects.geoapify.com/) แบบ Free ใช้คีย์เดียว
สำหรับ Geocoding และ Routing ได้ ไม่ต้องผูกบัตรหรืออัปเกรดแพ็กเกจ

ที่ `D:\campus-navigator` เปิด `backend/.env` ด้วย editor หากยังไม่มีไฟล์ให้คัดลอก
`backend/.env.example` ก่อน **อย่าทับค่าฐานข้อมูล/คีย์อื่นที่มีอยู่** เพิ่มหรือแก้บรรทัด:

```dotenv
GEOAPIFY_API_KEY=ใส่คีย์ของคุณบนเครื่องนี้
GEOAPIFY_DAILY_REQUEST_LIMIT=1000
```

หลัง merge แล้วรัน:

```powershell
git pull origin main
docker compose up --build
```

Compose อ่าน `backend/.env` เฉพาะ backend ไม่ใส่คีย์ใน frontend bundle
env_file แบบ optional ต้องใช้ Docker Compose 2.24.0 ขึ้นไป (ตรวจ `docker compose version`)
เมื่อเปลี่ยนคีย์ ใช้ `docker compose up -d --force-recreate backend` เพื่อสร้าง container ใหม่
การใช้เพียง `docker compose restart` ยังคง environment เดิม
ถ้าไม่มีคีย์ เว็บและเดโม่ยังเปิดได้ ปักหมุดเองและเปิด Google Maps ได้
ค้นหา/คำนวณเส้นทางจะไม่สร้างผลปลอมขึ้นมา

รัน Python โดยตรง: ทำจาก backend และรัน `python -m app.migrations.upgrade` ก่อน
`uvicorn app.main:app --reload` Docker รัน migration v004 ให้อัตโนมัติโดยไม่ลบข้อมูลเดิม

คีย์ฝั่ง server ใช้ข้อจำกัด IP ของ IP ขาออกจริงเมื่อมี IP คงที่ ไม่ใช้ HTTP referrer/origin
ของ `localhost:3000` เพราะคำขอไป Geoapify ออกจาก backend
ไม่ commit `.env`, ไม่ส่งคีย์ในแชต/ภาพ และไม่เปิด HTTP client debug logs ที่อาจมี URL พร้อมคีย์

## โควตา

ตรวจเอกสารวันที่ 2026-09-27:

- Free: 3,000 credits/วัน ใช้ร่วมระหว่าง API ในโปรเจค สูงสุด 5 คำขอ/วินาที
- Geocoding: 1 credit ต่อคำขอ Routing สองจุดมีค่าพื้นฐาน 1 credit
  เส้นทางยาวเกิน 500 กม. และรายละเอียดพิเศษอาจคิดเครดิตเพิ่ม
  แอปนี้ไม่ขอ elevation, route_details, alternatives หรือ optimize stops
- ค้นหาหนึ่งรอบ + เส้นทางสองจุดหนึ่งรอบในระยะสั้น โดยทั่วไปประมาณ 2 credits
- ไม่ยิงขณะพิมพ์ ป้องกันกดซ้ำระหว่างรอ ไม่ค้นคำเดิมซ้ำเมื่อผลยังแสดง
  backend cache 60 วินาทีในหน่วยความจำ สูงสุด 128 รายการ ไม่เก็บที่อยู่/พิกัดใน DB
- ก่อนเรียกผู้ให้บริการ จำกัดทั้งแอปห่างกันอย่างน้อย 0.3 วินาที
  และเริ่มต้นที่ **1,000 คำขอ/วัน UTC** เพื่อเผื่อเครดิตเส้นทางและการทดลองนอกเว็บ
  คำขอที่ล้มเหลวก็นับ ไม่ retry ผู้ให้บริการอัตโนมัติ
- ตาราง `outdoor_usage` เก็บเฉพาะวัน จำนวนคำขอ และเวลาที่เรียกครั้งถัดไปได้
  ใช้ร่วมทุก worker ไม่หายเมื่อ restart; วันใหม่ UTC ตรงกับ 07:00 น. ในไทย
- **ตัวนับในแอปนับคำขอ ไม่ใช่เครดิตทางการ** ไม่รวม Playground/แอปอื่นที่ใช้คีย์
  จึงไม่รับประกันว่าเครดิตจะไม่เกิน โดยเฉพาะเส้นทางไกล ต้องดู Usage & statistics ด้วย
  การล้างฐานข้อมูลล้างตัวนับแอป แต่ไม่ล้างยอดที่ Geoapify

เมื่อเกินขีดจำกัดหรือได้ 429/timeout เว็บอธิบายและให้ปักหมุด/เปิด Google Maps ต่อ
ไม่แก้โดยสร้างคีย์หรือบัญชีเพิ่มเพื่อหลบโควตา

## ข้อมูลและการทดสอบ

คำค้นส่งใน POST body ไป backend แล้วส่งต่อ Geoapify เมื่อผู้ใช้กดค้นหา
กดดูเส้นทางจึงส่งพิกัดต้นทางและทางเข้าให้ Geoapify Google Maps ได้พิกัดเมื่อกดลิงก์เท่านั้น
จุดเริ่มต้นไม่ถูกเก็บใน URL, localStorage, sessionStorage หรือ DB; มี cache ชั่วคราวตามข้างต้น
refresh/เปลี่ยนห้องจะล้างจุดเริ่มต้น การยกเลิกไม่คืนเครดิตของคำขอที่ส่งออกไปแล้ว

แสดงเครดิต Geoapify และแหล่งข้อมูลข้างผลค้นหา/เส้นทาง พื้นหลังยังเป็น OpenStreetMap
การทดสอบอัตโนมัติจำลองผล provider ไม่ใช้คีย์จริง ไม่ยืนยันคุณภาพข้อมูลไทย
หลังใส่คีย์ให้ลองสถานที่รอบมหาวิทยาลัย 5–10 แห่ง ตรวจชื่อซ้ำ เส้นทางเดิน/รถและทางเข้า
หอพักที่ไม่พบให้ค้นถนนใกล้เคียงหรือปักหมุดเอง ข้อมูลสำรวจจริงยังจำเป็น
